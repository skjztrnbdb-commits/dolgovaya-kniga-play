# Долговая книга

Экономический рогалик: торговая контора достаётся вам вместе с чужим долгом под сложный
процент. Возите товар между пятью рынками и рассчитайтесь раньше, чем проценты вас закопают.
Один заход — 20–50 минут.

**Играть: https://skjztrnbdb-commits.github.io/dolgovaya-kniga-play/**

Игра целиком браузерная: статичные файлы, ни одной внешней библиотеки, ни шага сборки.
Прогресс хранится в вашем браузере.

Этот репозиторий — витрина: сюда автоматически выкладывается собранная игра. Разработка
идёт в отдельном репозитории.
