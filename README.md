# The Debt Ledger

**Play: https://skjztrnbdb-commits.github.io/dolgovaya-kniga-play/**

An economic roguelike. You inherit a trading house together with its debt —
$20,000 at 2% a day — and you have 30 days to clear it. Five markets on a road
graph, one day per road. Every market charges a spread, so buying and selling in
the same place always loses money: you have to keep moving, and the interest
compounds while you do. One run takes 20–50 minutes.

Also on itch.io: https://nexthardstep.itch.io/the-debt-ledger

## How it is built

No engine, no libraries, no build step, no server. One HTML file, one stylesheet
and sixteen classic `<script>` tags — about 150 KB in total. It runs if you open
`game/index.html` straight from disk. Everything on screen is text, tables and
SVG generated by the layout code; the sounds are oscillators; saves are
`localStorage`. The only external request is Google Fonts, and it degrades to
system fonts.

```
game/
  index.html   markup and the ordered list of <script> tags
  style.css    all of the layout
  sw.js        service worker: the game works offline
  js/
    data.js         static data and balance numbers
    lang-ru.js      every Russian string
    lang-en.js      every English string (same keys)
    lang.js         language switching
    state.js        run state, small pure helpers, storage
    ui.js           sound, toasts, confirmations
    telemetry.js    play-session log, exported as TSV by the player
    economy.js      hold, pricing, quotes, paid services
    contracts.js    contract offers, acceptance, delivery
    world.js        day change, travel, disasters, run start and finish
    trading.js      buying and selling
    render.js       the game screen — the only place that draws a run
    render-phone.js the same run rearranged into tabs on a narrow screen
    tutorial.js     lesson scripts and the step engine
    tutorial-ui.js  the tutorial layer over the game
    main.js         button handlers, loaded last
```

Two deliberate choices that explain most of the code. The scripts are **not** ES
modules: modules are blocked by CORS when you open a file directly, which would
break the "it runs from disk" rule, so the files share one global scope in a
fixed order. And every string lives in a language pack as a **function**, not as
a template with holes — Russian and English build a sentence differently, and a
shared skeleton makes both of them slightly wrong.

## Disclosure

The game was designed by someone who does not program; the code and all of the
text were written by an LLM (Claude). There is no generated art or audio, because
there are no art or audio assets at all. The itch.io page carries the same
disclosure under their AI policy.

This repository is a mirror: it holds the built game and nothing else. Each
release overwrites it in a single commit, so there is no development history here.
